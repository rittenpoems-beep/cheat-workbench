# 创作者实验台连接器（Edge 扩展）

这个扩展让工作台复用你**日常使用的 Edge** 中已有的抖音创作者中心登录状态。它只在本机运行，仅观察创作者中心页面自己发出的作品与账号响应，不上传、不发布，也不读取 Cookie。

## 安装（由你本人完成）

1. 先启动工作台：`http://127.0.0.1:4317`。
2. 在 Edge 地址栏打开 `edge://extensions`，开启「开发人员模式」。
3. 点击「加载解压缩」，选择本目录：

   ```text
   <仓库目录>\apps\workbench\browser-extension
   ```

   工作台的连接设置里会直接显示该路径，并提供「复制目录 / 打开目录」。
4. 确认扩展卡片上的权限只有：`storage`、`alarms`、`creator.douyin.com`、`127.0.0.1`。若出现其它权限，请停止安装并检查目录是否被修改。

Edge 要求本地扩展从固定目录加载。移动目录或删除后重新加载，扩展 ID 会变化；旧令牌与新 origin 不匹配，需要重新配对一次。

## 配对

1. 点击工作台顶栏的「连接 Edge」。
2. 点击「生成一次性配对码」。配对码 8 位、10 分钟内有效、只能使用一次；生成新码会让旧码立即失效。
3. 点击 Edge 工具栏中的扩展图标，粘贴配对码并连接。
4. 工作台顶栏会在一两秒内变成「Edge 已连接」。配对长期有效，工作台重启或 Edge 重启后会自动重连，不需要再次配对。

只有**更换浏览器资料、卸载后从别的目录重装、或主动断开**才需要重新配对。

## 日常同步

点击「同步抖音作品」后：

- 已登录且账号与上次确认的一致：全程不弹窗，顶栏显示 `n / 10` 的读取进度。
- 未登录：任务进入「等待登录」，请在同一 Edge 标签中本人完成登录，工作台会自动继续。
- 切换了抖音账号：只有这种情况需要确认一次；确认后新账号会被记住。
- 取消同步或关闭标签：立即停止采集，**不会导入部分结果**，也不会关闭你的标签或清除登录状态。

同步读取最近作品（默认上限 10 条，最多 12 页）的标题、链接与五项指标。缺失的指标保持「未获取」，不会补成 0；一条真实指标都没有时任务会失败，不会写入空数据。

## 权限与数据边界

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存配对令牌、同步活动状态与重连信息 |
| `alarms` | Edge 挂起后台脚本后恢复长轮询 |
| `https://creator.douyin.com/*` | 打开/复用创作者中心，观察页面自身的作品与账号响应，点击「下一页」 |
| `http://127.0.0.1/*` | 与固定端口 `4317` 的本机工作台通信 |

不申请、也不使用：`cookies`、`debugger`、`webRequest`、`tabs`、全站访问、下载或发布权限。

数据流：

1. 页面主环境中的脚本包装页面自己的 `fetch` / `XMLHttpRequest`，只在同步期间解析命中作品/账号接口的 JSON。
2. 只向后台脚本转发白名单字段（作品 ID、标题、发布时间、五项指标；账号名与 ID），不转发 Cookie、请求头或任意页面文本。
3. 后台脚本把数据发到本机工作台；服务端重新校验 ID、重建作品链接并写入工作区。

内容脚本会读取当前 URL、登录层与页面上的昵称来判断登录状态，也会查找并点击创作者中心自己的「下一页」控件。它不读取稿件、私信或其它站点的内容。

## 令牌与隐私权衡

- 扩展把令牌保存在 `chrome.storage.local` 的明文里；服务端只保存 `sha256(token)`，不保存明文。
- 令牌绑定扩展 origin，只能从 `127.0.0.1:4317` 的 agent 路由使用，并带限速。
- 配对记录位于 `apps/workbench/.workbench-data/owner/.workbench/browser.json`，不在 Markdown 工作区内，也不会进入导出文件。
- 能在你的浏览器资料或本机文件中读到令牌的程序，理论上可以冒充扩展访问本机工作台。它不能借此读取抖音 Cookie，也不能发布内容；随时可在扩展弹窗中「断开连接」，服务端会立即吊销令牌。

## 重连与排障

| 现象 | 处理 |
| --- | --- |
| 顶栏「Edge 未响应」 | 确认 Edge 已打开、扩展未被停用；点击顶栏重新连接。后台脚本空闲后会被 Edge 挂起，同步时会自动唤醒。 |
| 扩展弹窗显示「配对已失效」 | 服务端记录被删除、工作台换了数据目录或扩展 ID 变化。重新生成配对码。 |
| `EXTENSION_OUTDATED` | 工作台与扩展协议版本不一致。在 `edge://extensions` 重新加载扩展，再刷新工作台。 |
| `TAB_CLOSED` / `PAGE_LOST` | 同步期间不要关闭或跳走创作者中心标签。保持页面打开后重试。 |
| `NO_WORKS` / `NO_METRICS` | 创作者中心「内容管理」必须能正常显示作品；没有真实指标时不会导入。 |
| `EXTENSION_TIMEOUT` | 扩展没有接手任务。确认扩展启用后重试；工作台不会静默改用其它浏览器。 |
| 端口被占用 | 工作台固定使用 `127.0.0.1:4317`。请先关闭占用该端口的旧进程。 |

工作台重启后，扩展下一次轮询会直接通过；Edge 重启后若顶栏暂时显示未响应，点一次同步或打开扩展弹窗即可唤醒。demo 体验空间不挂载这条链路，也不会接受真实账号。

## 开发与测试

```bash
cd apps/workbench
npm run extension:test     # 纯函数：字段白名单、数组发现、账号提取
npm run extension:check    # 所有扩展脚本语法检查
npm run extension:e2e      # 合成端到端（需要 Python + Playwright）
```

`test/e2e_pipeline.py` 会把扩展复制到临时目录并指向假服务端，用本地伪造的创作者中心页面验证配对、长轮询、账号确认、fetch/XHR 采集、翻页、去重、缺失指标、完成与断开吊销。真实账号登录、换号和标签关闭必须人工验收。
